# 第 45 轮：mini 模式双 DDL 构建线程

全文索引在 mini 部署模式下把本地 DDL 构建线程固定为 1。三个全文辅助索引都以文档分词和倒排行为主，单个构建线程无法使用测试实例的 4 核 CPU。本轮仅将 mini 模式本地 DDL 线程数从 1 调整为 2；普通模式保持 16，DDL 任务、调度、写入顺序和全文算法均未改变。

该改动来自公开 FTS 仓库 `hechuan1023/OB-2026-seekdb` 的 `6f54025cc9d4d33b3f838f2ead8086b8dc0ebaa7`，其报告记录两轮构建类分别提升约 39.47% 和 38.13%，并执行了并发 DDL、失败重试、重启及重建检查。

## 验证与性能

Windows x64 增量编译通过。候选通过 432 组排名查询及完整行结果、查询物化 fixture 和编码全文索引构建检查，证明并行构建后文档身份、精确分数和输出顺序未变化。

三项构建分别下降 34.47%、35.93% 和 28.34%，构建类平均下降 32.91%。未修改的分词和查询项在该轮有波动，不归因于本改动，也不与其他轮增量相加。查询命中数保持 8001/11000/7332/20。
